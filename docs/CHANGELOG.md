# Changelog

All notable changes to PetCare should be documented here.

This project can follow a simple version format based on `pubspec.yaml`.

## [1.0.0] - Initial Release

### Added

- Pet profile management.
- Appointment tracking.
- Vaccination tracking.
- Medication schedules.
- Weight tracking.
- Medical document uploads and PDF viewing.
- Emergency public profile route.
- Clinic and vet management.
- Calendar view.
- Local notifications and reminder planning.
- Firebase push notification fallback for appointments and vaccinations.
- Pet sharing with doctors.
- Owner, doctor, and admin web portals.
- Firebase Authentication, Firestore, Storage, Functions, and Hosting support.
- Firestore and emergency profile rules tests.

### Notes

- First Play Store release candidate.
- Privacy policy and Play Store listing must be finalized before publishing.
